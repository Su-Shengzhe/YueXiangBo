# 业务契约 M1（2026-10-23 初始基线）

本文件补充现有七份设计说明书，约束当前可运行增量，不替代最终设计。技术预研收尾与第 3—4 周简化演示链路共用此契约。正式结算、对账和真实 AI 尚未交付。

## 1. 通用约定

- 网关：本地业务环境 `http://127.0.0.1:9090`，前缀 `/api/v1`；原有8080探针环境独立保留。
- 成功/失败均返回 `{code,message,data,traceId,serverTime}`，使用真实HTTP状态。成功code=OK；失败data=null。serverTime是真实UTC时间；演示业务时间由/demo/clock单独返回。
- ID使用十进制字符串，金额整数分，时间带时区的ISO 8601；预约区间为[startAt,endAt)。公开订单标识统一reservationId；车辆/车位标识为id。
- 登录返回RS256 Bearer JWT，15分钟有效，只存浏览器内存。业务服务验证签名、issuer、audience、有效期，再向身份服务核验会话、账号状态及当前角色；身份依赖不可用时拒绝受保护请求。退出即时撤销会话。
- 创建预约、支付和物业入离场须带Idempotency-Key，为8—80位字母、数字、连字符或下划线。同用户、操作、键、参数重放原响应；同键不同参数409。网络结果未知时沿用原键重试，再GET最新状态。旧幂等响应不得覆盖最新查询结果。
- 列表最多100条，演示单社区；分页、批量管理后续实现。页面显隐不是权限校验。
- /internal/v1/**不由网关转发，内部请求还须共享服务令牌。
- 角色为DRIVER、OWNER、PROPERTY、PLATFORM。演示账号使用本地随机凭据；无公开注册、默认通用密码或真实支付密钥。

机器可读的OpenAPI 0.2.0已补齐当前公共业务接口；需求、AI只读工具和实现追踪见[M1初始基线](../M1需求与接口初始基线.md)。

## 2. 首批五项契约

| 接口 | 输入 | 输出data | 权限与关键错误 |
|---|---|---|---|
| POST /auth/login | JSON：username（1—40位字母数字下划线）、password（最多100字符） | accessToken、expiresIn=900、user:{id,username,roles,communities} | 公开；401 BAD_CREDENTIALS，403 ACCOUNT_DISABLED，429 LOGIN_RATE_LIMIT；按来源地址和账号一分钟最多10次 |
| GET /vehicles | Bearer | [{id,userId,plate}] | 仅本人车辆；401 UNAUTHENTICATED/SESSION_REVOKED；身份依赖不可用503 |
| GET /spaces/available | query：communityId、startAt、endAt | [{id,communityId,ownerId,name,hourlyFen,enabled,estimatedFen}] | 公开；422 TIME_ALIGNMENT/INVALID_INTERVAL；查询只是快照，创建时重检 |
| POST /reservations | JSON：vehicleId、spaceId、startAt、endAt；幂等键 | reservationId、userId、vehicleId、spaceId、communityId、plate、hourlyFen、startAt、endAt、payDeadline、prepayFen、overtimeFen、status、enteredAt、exitedAt、version、createdAt、entryBlockedAt、closeReason | DRIVER本人车辆；403 VEHICLE_FORBIDDEN；409 SPACE_DISABLED/OUTSIDE_SHARE_WINDOW/RESERVATION_CONFLICT/IDEMPOTENCY_CONFLICT |
| GET /bills/{reservationId} | 路径预约标识；Bearer | reservationId、userId、prepayFen、overtimeFen、paidPrepayFen、paidOvertimeFen、refundFen、status、version、reservationVersion、billVersion、attempts、settlementStatus | 仅订单本人；404 BILL_NOT_READY（尚未生成或不存在）、NOT_FOUND（非本人）；settlementStatus=NOT_IMPLEMENTED |

当前创建预约成功HTTP 200；异步付款受理202。列表为空是成功，不是404。下单示例：

```json
{"vehicleId":"40","spaceId":"20","startAt":"2026-10-23T01:00:00Z","endAt":"2026-10-23T02:00:00Z"}
```

示例时间须换成相对当前业务时间的未来时段。预约开始不早于15分钟后，起止均按15分钟对齐，30分钟≤时长≤24小时，结束不超过未来30天，完整落在一个共享窗口。车位和车辆在有效订单区间内均不得重叠。按车辆、车位、订单顺序锁稳定行，事务隔离READ COMMITTED。

价格与车牌在创建时快照。预约费及超时费分别按30分钟向上取整后计算，半小时金额出现半分时HALF_UP；500分/小时，1秒超时收250分。

## 4. 状态、消息与一致性

- 预约WAIT_PAY→CONFIRMED→IN_USE→COMPLETED；WAIT_PAY到10分钟截止后EXPIRED；开始15分钟后仍未入场，已有受阻记录或车位仍占用则转SPACE_UNAVAILABLE，其他转NO_SHOW；可取消时转CANCELLED。
- 只有付款事实到达且订单未过截止才确认预约。过期、取消或未到场后收到付款不得复活订单，发出关闭事件触发全额模拟退款。
- 先保存CREATED支付尝试，后台按原channelNo派发；模拟渠道独立事务保存结果；重启复用原号；入账和PaymentSucceeded事件同事务提交。订单行串行化活动尝试，渠道请求和账本有唯一约束。
- 跨库仅用RabbitMQ；停车和交易各写自己Outbox。发布确认后SENT，失败退避最多5次，耗尽FAILED；消费事件ID与业务变更同事务去重；处理失败重试后进死信队列。
- ReservationCreated、ReservationConfirmed、ReservationClosed、ParkingEntered、ParkingCompleted携带订单快照和version；交易投影只接受更新版本。金融事实独立处理，不因旧投影版本丢弃退款检查。
- 当前为每服务单实例的本地演示。多实例发号、支付派发租约、失败事件管理界面、人工退款、账单版本与争议结算属于后续落地项，不能以本增量替代正式财务验收。
- 消息最终一致，页面区分账单准备中、付款确认中和预约确认状态；不能仅以202认定付款/预约成功。

## 5. 模型桩边界

用户已确认先用模型桩，真实接口与预算稍后确定。当前无外部模型调用，费用0。桩固定回答、无写工具、无数据传往外部。独立执行器10线程、10排队位置、最多1秒排队等待、总截止20秒，模拟30秒延迟和异常。

仅能验收封装与故障隔离，不能验收自然语言理解、工具选择、检索、回答正确率或费用控制。真实供应商、模型、总预算、每日限额、私密凭据及只读工具调用小样均为后续准入条件。


## 2026-10-22 可靠性优化补充

- 计费按完整 Duration 向上取整，不能先截掉不足一秒的部分。500 分/小时：超时 0.5 秒收 250 分；超时 1800.5 秒收 500 分。
- 账单金额和 attempts 在同一订单行锁保护的事务内读取。所有交易尝试状态和金额写入都先锁同一 trade_order 行。version/reservationVersion 只表示预约事件投影；billVersion 随账单内容变化递增。
- 支付任务按笔隔离异常，采用持久化重试时间、30 秒租约及租约令牌。失败按 2、4、8、16 秒退避，达到 5 次进入 REVIEW。恢复始终复用原 channelNo；REVIEW 不是支付失败证明，不得新建另一笔扣款绕过核查。
- Outbox 每轮最多发送 20 条，逐条领取，完成写回校验 lease_token；遇到渠道不可用停止本轮并退避。仍采用至少一次投递，消费者幂等不可删除。
- 内部 GET /internal/v1/outbox/status 需 X-Service-Token，返回各状态数量、最老待发送年龄、死信数量及 brokerReachable；死信数量 -1 表示不可读取，不能解释为 0。网关不暴露此接口。
- 登录限流的计数与 TTL 在一个 Redis Lua 脚本中执行，发现旧键无 TTL 时保留计数并补上期限。
- 前端查询条件变化立即清除旧报价；异步查询返回时再次核对条件。当前账单必须与所选预约编号一致才可付款。AI 加载状态独立于业务按钮。
- 动态业务 ID 在各服务数据库内，通过 business_sequence 事务行锁分配，迁移从已有最大值初始化。ID 仅在对应服务资源范围内唯一，API 仍使用字符串；不是跨服务全局编号。
- business.demo 默认 false，Start-Business.ps1 显式为本地演示开启；关闭时不初始化演示账号/车位、不应用演示时钟偏移，禁止推进时钟和 AI 故障模拟。

## 2026-10-23 基础修复接口增量

OpenAPI 0.2.1新增 `POST /demo/windows?spaceId=20`（parking-service）。仅PLATFORM且business.demo=true可调用；锁定启用车位后，在已有最晚窗口之后追加15分钟对齐的窗口，最晚至业务时钟未来30天，既有窗口和预约不变。响应data为 `{created,spaceId,windowId?,startAt?,endAt?}`，无须添加时created=false；403 FORBIDDEN/DEMO_DISABLED、404 NOT_FOUND、409 SPACE_DISABLED。重复调用在相同可用时间范围内不会重复创建，并发由车位行锁串行化。
