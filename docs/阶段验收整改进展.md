## 已修改

- 验收器默认每15秒开始一个样例，可通过AI_EVAL_INTERVAL_MS配置。该默认值是保守执行策略，不代表供应商承诺限额。
- 遇到AI_BUSY或AI_PROVIDER_COOLDOWN停止本轮后续真实请求，剩余项记BLOCKED，不自动重试或拼接成功结果。
- 失败记录增加sessionId、requestId、responseStatus、fallbackReason、routeVersion。前置失败无请求ID时保留为空，不伪造关联。
- 能力门槛按27/30、27/30、18/20、20/20计算；存在阻塞时返回BLOCKED。能力通过仍须独立工程验收，不自动签收M4。
- HTTP 429解析Retry-After秒数或HTTP日期；无效值默认60秒，最短1秒、最长24小时。相同地址和凭据的路由共享当前进程内冷却状态。
- 模型调用在额度预留前检查冷却，阻止已知冷却期间新增请求；无自动模型重试。并发检查与发送之间仍有竞争窗口，不能宣称完整并发准入已实现。
- 无工具调用时解析明确CLARIFY/missing或REFUSE结构；未知文本、空追问、非法字段作为响应错误降级，不再一律追问。追问文案由服务端按字段生成。
