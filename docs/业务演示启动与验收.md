## 1. 一次初始化、启动与停止

在项目根目录用PowerShell 7执行：

```powershell
.\scripts\Initialize-Business.ps1
.\scripts\Build-Backend.ps1
.\scripts\Start-Business.ps1
.\scripts\Start-BusinessFrontend.ps1
```

访问 `http://127.0.0.1:5174`。首次初始化前启动Docker Desktop。前端依赖如未安装，先执行 `. .\scripts\Use-Toolchain.ps1`，进入frontend执行 `npm ci`。现有机器已安装依赖。

Start-Business会核对最近一次成功构建、源码指纹和JAR哈希；源码改变后必须重建。构件复制到独立运行目录，重建不会覆盖正在运行的JAR；需要升级服务时先Stop-Business，再Build、Start。启动失败只回收本次新建的进程，保留已复用服务。脚本不会删除数据卷。

```powershell
# 停止本项目业务Java服务和前端，保留基础组件与数据
.\scripts\Stop-Business.ps1
# 同时停止业务基础组件，仍保留数据
.\scripts\Stop-Business.ps1 -Infrastructure
```

测试脚本会启动独占的5174浏览器测试服务器；执行浏览器测试前先停止通过Start-BusinessFrontend启动的前端。可先Stop-Business后Start-Business（仅后端），再运行测试。不要杀死不属于本项目的占用进程。

## 3. 手动演示顺序

1. driver登录，选择默认未来时间和本人车辆，点击查询车位。
2. 预约A区-020。系统生成10分钟付款截止，打开账单；异步生成期间可刷新。
3. 点击模拟支付预约费。等待“预约已确认”，不要将受理提示当作付款成功。
4. 退出，admin登录，在“演示时间”推进到预约开始时刻。时钟使用文件保存偏移，仍随真实时间向前运行，不能倒退。推进影响所有演示订单。
5. property登录，在该订单办理入场。必须处于开始后15分钟内。
6. admin推进到预约结束后；property办理离场。超时1秒按半小时收取250分。
7. driver再次登录，打开该预约账单并模拟支付超时费。500分预约费+250分超时费=750分。
8. 另建未来预约，付款确认后取消，观察退款异步成功且仅一笔。
9. 打开停车助手，仅显示模型桩回答，不产生外部调用或真实费用。

JWT过期按真实时间计算，15分钟后重新登录。演示时间推进不影响JWT过期。支付不发生真实扣款，账单明确展示正式结算尚未实现。

## 5. 运维与未完成项

Outbox超过5次发布失败会标记FAILED，不静默丢弃。修复消息连接后，使用带事件ID的脚本重试指定失败事件：

```powershell
.\scripts\Retry-BusinessOutbox.ps1 -Service parking -EventId <事件UUID>
```

脚本仅更新该服务、指定事件且status=FAILED的记录。查看死信队列需结合日志与业务原因处理，不能直接清空队列或篡改账本。持续异常会留下失败记录和日志，本增量尚无告警管理台。

后续按原计划推进：注册及完整角色授权、车辆维护、车位发布审核与共享窗口管理；规则版本、通知、正式支付退款恢复边界、结算对账；分页、Vue Router/Pinia页面组织、完整管理后台及全容器Compose部署。当前只以Vue组件状态实现首条页面流程，基础组件容器化、业务服务本地运行，不能宣称完成最终部署。

AI真实供应商、模型、预算、每日限额与密钥暂不配置。后续采用被忽略的本地私密文件接入，先做真实只读工具调用小样与HTTP资源隔离，再开展任务完成率、引用与成本评测。当前固定模板和故障测试不计入AI能力验收。

### 项目目录改名后的路径检查

私密的deploy/.env.business中JWT_PRIVATE_FILE、JWT_PUBLIC_FILE、BUSINESS_CLOCK_FILE为本机绝对路径。移动或改名目录后，先备份配置并核对原密钥、时钟文件确实位于新目录，再更新这三个路径。保留原凭据、PEM内容和时钟偏移；不要重生成密钥、重置时钟或删除数据库卷。自定义外部密钥路径不得直接改为默认路径。已有进程必须通过Stop-Business.ps1核对所有权后停止，再启动。

## 第5—6周资源管理

账号注册后默认司机，由平台管理员在“用户与角色”搜索用户授予OWNER或PROPERTY。在“社区管理”通过物业选择器授权社区；受影响用户重新登录。业主发布车位，所属物业审核后，业主设置单次共享窗口。单价输入为元/小时。新司机绑定车辆即可查询并预约，旧停车账单流程继续使用。

复验顺序：Build-Backend.ps1 → Test-Week56Migrations.ps1 → Stop-Business.ps1 → Start-Business.ps1 → Test-Week56.ps1 → Test-BusinessBrowser.ps1 → Test-Business.ps1 → Test-BusinessReliability.ps1 → Test-BusinessRecovery.ps1。数据库备份须先准备；迁移脚本只在自身前缀隔离库执行。浏览器测试需要5174空闲，结束后运行Start-BusinessFrontend.ps1恢复演示页面。测试会推进演示时钟并保留模拟数据，不并行运行。

接口与异常说明见[第5—6周契约](contracts/业务契约-第5—6周.md)。停用社区或封禁车位不自动取消旧单；无法履约异常入口仍属第7—8周。结算对账及真实AI尚未交付。
