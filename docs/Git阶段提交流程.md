# Git 阶段提交流程

用户于 2026-10-28 授权：每个阶段验收完成后，提交并推送到 GitHub 远程仓库 `https://github.com/Su-Shengzhe/YueXiangBo`。

阶段提交前检查本轮差异与验收报告，将实现、必要测试、迁移和可分享验收证据一并提交。不得提交本机凭据、私钥、环境配置、数据库备份、运行目录、依赖目录和构建产物。个人 IDE 修改不纳入阶段交付。

提交成功后执行普通推送，校验远程提交号与本地一致，再向用户报告提交号和结果。远程存在新提交时先检查和整合，不强制覆盖。部分完成的阶段可提交已有成果，但提交说明及报告必须保留尚未通过的验收项，不将其标记为整体完成。
